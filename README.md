# 求职招聘小程序劳务派遣系统灵活用工 APP 源码搭建

这套求职招聘劳务派遣源码采用 UniApp 开发，一套代码可编译小程序、H5、APP，快速搭建灵活用工人力平台，适配劳务派遣、临时工、兼职招工业务。求职者可创建简历、检索岗位、投递简历、在线沟通，记录工时并查看薪资结算信息；企业方完成资质认证，发布岗位，筛选人才，管理派遣员工入职流程。

系统内置用工档案管理、线上合同留存、工时统计、薪资核算、财务对账模块。后台划分管理员、企业、求职者、劳务经纪人多角色权限，支持实名认证、消息推送、岗位审核、佣金结算、多维经营报表。搭载推荐裂变机制，经纪人推荐候选人入职可获得赏金，助力岗位引流拓客。
